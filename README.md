# Bryant Sylfen Tan — Portfolio

## Run locally in Visual Studio Code
1. Extract `bryant-portfolio.zip`.
2. Open the extracted `bryant-portfolio` folder in VS Code.
3. Install the **Live Server** extension (Ritwick Dey).
4. Right-click `index.html` → **Open with Live Server**.

## Add your profile photo
Put your portrait in the `assets` folder and name it exactly `profile.jpg`.
The site currently uses temporary CSS artwork for project thumbnails. These can be replaced with real screenshots later.

## Publish with GitHub Pages
1. Create a GitHub repository named `bryant-portfolio`.
2. Upload the contents of this folder; keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to publish; the site URL appears in Pages settings.

## Structure
- `index.html` — portfolio content
- `css/style.css` — visual design and responsive layout
- `js/script.js` — mobile navigation and current year
- `assets/profile.jpg` — add your own portrait
